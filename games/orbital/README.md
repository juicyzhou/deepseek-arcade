# 星环守卫 · 轨道哨兵（Orbital Sentinel）

极简霓虹圆环 360° 防御游戏 —— 你的哨兵飞船在中央恒星的环形轨道上旋转，
转动**护盾圆弧**弹反从四面八方袭来的陨石，守护恒星不灭。

## 🎮 玩法

- **转动护盾**：← → 键旋转，或按住拖动（触屏/鼠标）让护盾跟随指尖角度
- 陨石越过轨道环时，若正对护盾圆弧 → **弹反**：得分 = 10 × 连击数
- 未挡住的陨石击中恒星 → 扣 1 心（共 3 心），连击清零
- ✨ **星尘**：收集可扩展护盾宽度（最多 +27°），额外加分
- 难度随时间递增：陨石更快、更密集；恒星湮灭即游戏结束

## 🕹️ 操作

| 操作 | 方式 |

| 暂停 / 继续 | `空格` / `P` / `Esc` |

## ✨ 特色

- **环形几何美学**：霓虹轨道环 + 渐变护盾光弧 + 旋转刻度，极简而富有张力
- **哨兵飞船**：护盾中心的紫色飞船随环游弋，弹反时迸发冲击环与火花
- **动态恒星**：脉动辉光 + 旋转光芒；被击中时全屏红光警示与屏幕震动
- **连击系统**：环心上方实时显示 ×N，连击音效随连击数升高音调
- **星尘扩展**：收集四角星尘让护盾变宽，形成成长反馈
- WebAudio 合成音效 · 触屏 + 键盘 · 玻璃拟态 UI · `?autoplay` 演示模式
