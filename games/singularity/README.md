# 星噬 · 黑洞吞噬（Singularity）

在星海中吞噬成长的黑洞养成游戏 —— 你是一粒苏醒的黑洞，用**引力牵引**在星海游弋，
吞噬小天体不断壮大，与三个 AI 黑洞竞逐，90 秒内成为最大的奇点。

## 🎮 玩法

- **按住拖拽**（鼠标 / 触屏）产生引力牵引点，你的黑洞被拉向该处；松开后凭惯性漂移
- 吞噬半径比你小约 8% 以上的天体（恒星 / 行星 / 彗星）→ 质量与半径成长
- 避开更大的天体与黑洞 —— 会被撕裂
- 吞噬 AI 黑洞可获得其质量 ×2 的巨额奖励
- 90 秒倒计时结束或死亡后结算排名（1~4）

## 🕹️ 操作

| 操作 | 方式 |
| --- | --- |
| 引力牵引 | 鼠标按住拖拽 / 触屏按住滑动 |
| 微调助推 | 方向键 / WASD |
| 开始 / 重新开始 | `空格` / `Enter` / 点击按钮 |
| 暂停 / 继续 | `空格` / `P` / `Esc` |
| 静音 | 右上角 🔊 |

## ✨ 特色

- **吸积盘视觉**：黑洞由旋转的暖橙→紫罗兰椭圆吸积盘 + 纯黑事件视界 + 辉光构成，AI 黑洞色相各异
- **引力物理**：天体会被附近黑洞吸引，形成动态星海；弱引力设计鼓励主动狩猎而非挂机
- **出生保护**：开局 3 秒光环保护，避免被秒杀（真实玩家体验更公平）
- **吞噬特效**：螺旋吸入粒子 + 冲击环 + 屏幕辉光；质变（质量倍数成长）有升级音效与提示
- **竞逐排名**：实时显示 1~4 名，第 1 名带皇冠；最佳质量本地记录
- WebAudio 合成音效 · 触屏 + 键盘 · 玻璃拟态 UI · `?autoplay` 演示模式
