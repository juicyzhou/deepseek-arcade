# 流光 · 贪吃蛇（Aurora Serpent）

一款**风格迥异**的贪吃蛇 —— 放弃传统方块像素风，采用「**极光星海 × 流光丝带**」的设计语言：
蛇身不再是僵硬的小方块，而是一条在星海中游弋、由青到品红渐变的**发光丝带**；食物是脉动的**能量星**；
背景是深邃星空、漂移星云与闪烁繁星。搭配玻璃拟态 UI、合成音效与粒子特效，让经典玩法呈现全新的视觉体验。

![风格] 极光丝带蛇 · 星空星云 · 玻璃拟态 · 流光字效

## ✨ 特色

- 🎨 **流光丝带蛇身**：蛇在网格间**平滑插值滑动**（非跳格），多层柔光叠加，头部带眼睛与辉光
- 🌌 **动态星空**：闪烁繁星、缓慢漂移的四色星云、暗角氛围
- ⭐ **能量星食物**：脉动光晕 + 旋转光环 + 环绕卫星，吞噬时迸发粒子与冲击波
- 🎵 **WebAudio 合成音效**：进食、升级、死亡、开始均有对应的程序化音效，可静音
- 💎 **玻璃拟态 UI**：毛玻璃面板、渐变流光标题、入场动画、得分弹跳动效
- 🕹️ **完整玩法**：等级加速、最高分本地记录、新纪录徽章、暂停/继续、穿越模式开关
- 📱 **多端操作**：键盘（方向键/WASD/空格）、触屏滑动、点击即玩
- 🔄 **主菜单演示蛇**：菜单背后有一条自动游弋的演示蛇，边看边玩

## 🎮 玩法

- 移动方向键或 WASD 控制蛇的走向，吃下能量星得分
- 每吃 5 颗能量星升级一次，速度加快，得分倍率提高
- 撞墙或咬到自己即游戏结束（可开启「穿越模式」穿过墙壁）
- 得分越高蛇越长，挑战性越大

## ▶️ 运行方式

无需构建，直接打开：

```bash
# 方式一：直接双击 index.html
open index.html

# 方式二：本地静态服务器（推荐）
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 🧠 实现要点

- **平滑运动**：记录每节蛇身的「上一格 / 当前格」，按步进进度插值渲染，60fps 丝滑游动
- **流光渲染**：`globalCompositeOperation: 'lighter'` 加法混合 + 逐段色相渐变，模拟霓虹光带
- **粒子系统**：火花（受重力与阻尼）与冲击环两类粒子，吞食 / 升级 / 死亡时触发
- **自适应**：Canvas 按设备像素比（DPR ≤ 2）渲染，宽高比随网格固定，移动端适配
- **状态机**：`menu → playing → paused/dying → over`，主菜单演示蛇复用同一套逻辑
