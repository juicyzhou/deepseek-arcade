# 星流节拍 · 音浪共振（Pulse Star）

**音乐全部由 WebAudio 实时合成**的放射状音游 —— 音符沿四条轨道涌向中央判定环，
在落环瞬间按下对应按键，Perfect / Good 判定，连击攒满能量触发**极光爆发 ×2**。

## 🎮 玩法

- 音符从四条轨道（D / F / J / K）的外端涌向中央光环
- 音符即将落环时按下对应键：提前 ≤45ms 为 **PERFECT**（+300），≤90ms 为 **GOOD**（+100）
- 漏接音符扣 1 格生命（共 5 格），连击清零；生命耗尽 → 星流紊乱
- **极光爆发**：Perfect 攒满能量弧 → 8 秒 ×2 得分 + 金色星海
- 难度递增：BPM 104→144、音符密度渐增
- 音乐随节拍实时合成：底鼓 + 贝斯 + 踩镲 + 五声音阶琶音

## 🕹️ 操作

| 操作 | 方式 |
| --- | --- |
| 四条轨道 | `D F J K`（触屏：屏幕分四区点击） |
| 开始 / 重新开始 | `空格` / `Enter` |
| 暂停 / 继续 | `空格` / `P` / `Esc` |
| 静音 | 右上角 🔊 |

## ✨ 特色

- **零音频资源**：整首曲目由 WebAudio 振荡器实时合成，随 BPM 与难度演化
- **放射霓虹美学**：四轨放射线 + 脉动判定环 + 能量弧，音符越近越亮
- **极光爆发**：能量蓄满时星海转金、双倍得分、爆发音效
- **判定反馈**：PERFECT/GOOD/MISS 浮动文字 + 冲击环 + 火花，连击数悬于环心
- 触屏四区点击 · 玻璃拟态 UI · `?autoplay` 演示模式
