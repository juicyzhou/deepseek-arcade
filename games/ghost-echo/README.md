# 双身迷宫 · 时间幽灵（Ghost Echo）

赛博故障风**回声解谜** —— 你的过去身（半透明幽灵）以 **2.6 秒延迟**复刻你的每一步。
让"过去的你"替你踩住压力板，现在的你穿过闸门；与自己的影子共舞，破解 5 座迷宫。

## 🎮 玩法

- **回声机制**：你走过的每一格，幽灵都会在 2.6 秒后重走一遍
- 幽灵**踩住压力板** → 闸门开启 → 你趁机通过（站立越久，幽灵守板越久）
- 幽灵**免疫激光**、可穿墙（它是时间回声，不是实体）
- ✦ **宝石**：集齐本关宝石出口才会开启；幽灵拾得宝石同样计分
- 🧊 **激光**：本体碰之即亡（重试本关）
- 共 5 关：教学 → 单板开门 → 门+双宝石 → 双门连过 → 双门+宝石+激光

## 🕹️ 操作

| 操作 | 方式 |
| --- | --- |
| 移动 | `← → ↑ ↓` / `WASD`（按住连续走） |
| 重试本关 | `空格` / `Enter` / 按钮 |
| 暂停 / 继续 | `P` / `Esc` |
| 静音 | 右上角 🔊 |

## ✨ 特色

- **时间解谜核心**：不是躲怪、不是找路，而是"编排自己的过去"——独一无二的机制
- **赛博故障美学**：霓虹网格迷宫、RGB 分裂的故障标题、随机扫描线故障闪烁
- **幽灵可视化**：半透明青色影子与本体错位游走，闸门开启/关闭动态变色
- **5 个手作关卡**：难度渐进，第 4 关起需要连续编排两个压力板接力
- **激光与宝石**：幽灵免疫激光的设定带来"只可意会"的规则趣味
- WebAudio 合成音效 · 触屏 + 键盘 · 玻璃拟态 UI · `?autoplay` 演示模式
