# 踏云行 · 水墨跳山（Ink Leap）

一幅会玩的水墨画 —— **蓄力跳跃**登高游戏。你是一个戴斗笠的墨点小人，
在毛笔绘制的祥云与山石间踏云而上，收集朱砂印章，直上青云。

## 🎮 玩法

- **按住蓄力、松开起跳**：蓄力越久跳得越高（脚下墨池随之扩散）
- **← → 移动**（键盘）；按住期间**滑动对准落点**（鼠标 / 触屏）
- 平台类型：
  - ☁️ **祥云 / ⛰ 山石**：普通落脚点
  - 🪷 **墨莲**：踩上自动弹跳更高
  - ⚡ **雷云**：一踩即碎，坠落失足
  - 🌫️ **游云**：水平漂移
- 🧧 **朱砂印章**：浮在空中的金币，收集加分
- 坠出屏幕底部（坠入云海）即游戏结束；高度与印章数计入成绩

## 🕹️ 操作

| 操作 | 方式 |
| --- | --- |
| 蓄力 / 起跳 | 按住 `空格` / `↑` / `W` / 鼠标 / 触屏，松开起跳 |
| 移动 | `← →` / `A D`；按住时滑动对准落点 |
| 开始 / 重新开始 | `空格` / `Enter` |
| 暂停 / 继续 | `P` / `Esc` |
| 静音 | 右上角 🔊 |

## ✨ 特色

- **国风水墨视觉**：宣纸底色、淡墨远山三层、漂移雾带、墨点飞鸟、毛笔笔触平台
- **斗笠小人**：墨点身体 + 斗笠，蓄力时墨池扩散、跳跃墨滴飞溅
- **印章收集**：朱砂方章 + 简笔「福」字，收集时红色印章爆裂特效与清脆音效
- **程序化登高**：平台间距随高度递增、难度渐进（雷云随高度出现）、无限向上
- **菜单演示**：主菜单背后有演示小人自动登高，边看边玩
- WebAudio 合成音效 · 触屏 + 键盘 · 宣纸玻璃 UI · `?autoplay` 演示模式
